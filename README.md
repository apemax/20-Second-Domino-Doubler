# 20 Second Domino Doubler

20 Second Domino Doubler was made for the 20 Second Game Jam 2026: https://itch.io/jam/20-second-game-jam-2026

In 20 Second Domino Doubler you have to pick two dominoes that add up to double the target domino in rank, See how many you can double in 20 seconds!

Play it on Itch.io here: https://apemax.itch.io/20-second-domino-doubler

Made with the DragonRuby Game Toolkit: https://dragonruby.org/

All art assets made with Pixelorama: https://orama-interactive.itch.io/pixelorama
